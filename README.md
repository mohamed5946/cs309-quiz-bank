# CS 309 Quiz Bank

بنك أسئلة مادة المعالجات الدقيقة ولغة التجميع (8086) — للتدريب على الميدتيرم.

- 80 سؤال: اختيارات (MCQ) وصح/غلط — مفيش مقالي.
- الإجابة النموذجية + شرح تفصيلي بالعربي بيظهر تحت كل سؤال بعد ما تختار إجابة.
- فلاتر حسب المصدر والموضوع، بحث، خلط، تدريب على الغلطات بس، وزرار «عشرين سؤال» بيجيب 20 سؤال عشوائي.

## المصادر
- التدريب (20 سؤال): تدريب الميدتيرم المعتمد.
- Assignment 1 (30 سؤال): من حل الـ Assignment بخط الإيد — مع تصحيح غلطتين في الحل الأصلي (MOV CS, AX غلط، و MOV AL, CH صح).
- Assignment 3 (14 سؤال): من أسئلة الـ Assignment (CALL/RET/JMP والـ stack وكود الآلة).
- أسئلة متوقعة (16 سؤال): من سلايدز شابتر 1 و 2 (د/ أشرف فهمي).

الأسئلة في `cs309-quiz-data.json`، والموقع في `index.html` (نفس تصميم بنك أسئلة H 201).
